# 007技术布局约定与尚未接入的功能

以下是实现约定，不是声称正式表存在新的平衡值。

- 只实现首母星可复用骨架接口，明确xingxing_03/body_0001；不猜其他天体特殊机制
- 使用42表半径400、直径800的有限包络。整数cell的中心为(x+0.5,y+0.5)，候选在半径内采样；入口7×7保护矩形全部角点须在包络内。中心距离使用欧氏格距离/平方比较；不环绕。完整正式玩家边界接入仍由后续整合验证
- 每个既有Biome保留一个技术核心位置；出生Biome核心位于所选出生cell。它们只是确定性分区入口，不是已校准面积比例或完整洞穴/生态分布
- 哈希域由生成版本、规范Seed、静态bodyID、功能域和局部attempt组成；不使用全局rand，不让美术/贴花消耗改变核心随机序列
- core_layout_fingerprint不包含临时world/connection实例ID或任何视觉选择；实际保存保留world/实例身份。生成版本改变必须明确处理，不靠读档重新跑生成器
- 每个入口层对保存独立上下端地址，校验两端cell相同、许可、3×3本体/7×7安全区、地图边界和距离保底。地下1继续向下按38 I7/M6/N6，不因G7=否取消
- max_region_attempts是调用方显式传入的实现重试限制，没有生产默认或调试Seed；128仅为本技术接口操作安全上限，不是游戏平衡数据
- 阶段记录按照cehua P180，未接入的关键模板/保护区、液体地形、资源/POI/树动物实际初始化不标complete。正常生成成功也只返回technical_world_layout_preview，formal_world_allowed=false
- 树动物密度、Biome面积/洞穴比例、必要材料最少数量等未见正式定值保持未配置。关键ID/已有权重/覆盖率不报缺失。未来保障表须依据正式配方推进要求追溯
- 预览保存目录user://generation_previews，独立于004正式世界schema。仅当前单权威进程，1MiB操作上限，临时文件flush后同目录rename；不声称跨进程并发写/断电安全/跨平台完整存档已验证。010集成正式保存前须复用已验锁与并发策略
- 文件保存实际核心位置/入口等已生成结果和受支持的永久清除记录。读取只校验/恢复，不调用生成器或随机源；缺/坏文件不“自动重生成修复”。来源/版本不兼容拒绝，未实现跨源版本迁移
