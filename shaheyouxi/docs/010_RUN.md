# 010 联机技术世界运行说明

本项目Godot4.6系列，已验证Linux4.6.3。游戏场景game/scenes/world_session010.tscn；同一脚本支持Host、专用服务器和真实客户端，固定绑定localhost，不改系统网络。

## 已验证一键生命周期入口
在root分配的专属≤2分钟窗口，桌面终端执行：

```bash
bash /workspace/shared/shaheyouxi_project/tools/desktop_world010_network.sh
```

入口延迟10秒供CUAreset，再由真实/sys/fs/cgroup准入。它运行Host+两客户端，保存并关服；使用相同世界目录和原私有客户端身份启动新专用服务器+两客户端，恢复后再次正常停服。峰3引擎、6独立PID；Godot合计352MiB，包含驱动的整个进程组384MiB，effective余量900MiB/raw底线192MiB，90秒命令110秒总，任何首失败收尾。

观察结果在evidence/010_latest_world_run.json。完整快照和本机游戏恢复身份仅在runtime/world010_<时间>/下；它們不会上传恢复包，不要发给其他人。公开证据只保留档案/实例ID等必要技术证明。

## 构建输入
```bash
python3 tools/data/world_bundle010.py
```

输入为009真实创作的asset_sources/prefabs/fixture_cua9.json，以及已核正式表投影generation_settings/prefab_settings；核验原始资料与投影hash后生成game/data/world_bundle010.json与授权hash文件。完整几何检查仍由Godot严格Validator执行。

正式数值调整应修改权威工作表并通过既有数据流水线重建相关投影，再重建此bundle。旧世界遇新bundle/source明确拒绝，不隐式迁移或重新生成；迁移政策在011.5。

## 运行形态与验证范围
这是具有真实联机层节点/实际Prefab对象/统一存档的技术世界。GUI观察代码直接读取同一服务器快照，显示三层点位/入口代理与出生点房间局部，最终v3PCK已实际GUI观察并正常F10退出；完整结果及截图在evidence/010_RUNTIME_RESULTS.md，仍不称正式可玩世界。F10请求正常关闭；技术入口有90秒测试超时，不是长期托管服务。

默认project.godot主场景仍是已有bootstrap，未把技术场景偷换为正式启动。已交付实际运行核验的Linux技术PCK ZIP（deliverables目录），依赖已装Godot/Python，不冒称Windows独立可执行成品；此PCK无需源缓存，冷恢复源码的导入预算仍独立。formal_world_allowed=false，人物操作接011。
