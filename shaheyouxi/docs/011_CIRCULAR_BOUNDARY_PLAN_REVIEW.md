# 011 圆边界接线方案评审

2026-10-05。仅方案：只读复核当前 ActorSpace、ActorJointSolver、ActorSessionController，未改运行代码、未启动引擎/CUA、未运行测试。

## 结论与范围

推荐“精确首次触边事件 + 贴边阶段的有限共同时间弦”，接入现有全体 preview → joint solve → 原 prepare/commit 票据流程。不能只把 `MAP_BOUNDARY_CLIP_REQUIRED` 替换成普通平面法线碰撞。

按本轮明确的原件边界：P53 要求完整碰撞体不出圆边并保留切向；P85 的 0.65 AABB 只约束 peer。保留当前环境圆，半径 r 取已核 ActorInputs（现 0.325），允许中心圆半径 ρ=正式地图半径 R−r，中心为该层本地原点。完整 Address.key 隔离。不换形、不扩大/缩小玩法圆、不做最近合法重连。

## 已确认的接线风险

- ActorSpace 当前整段终点越界即报错；controller.step 将求解失败转为 fatal，并释放 runtime。合法触边必须成为可消费剩余时间的运动约束。
- 圆边切线不是可行的正时长直线。ρ=10、p=(10,0)、d=(0,0.1) 时，终点长度约 10.0004999875。径向法线与 d 点积为零，普通 slide 不改变 d，再查询仍在同一时刻触边，会落入 `JOINT_CONTACT_NO_PROGRESS`。
- 不得先投影整个内部起始段的终点，再匀速走短线：ρ=10，A 从 x=9.9、B 从 x=9.2 同以速度 2 前进，tick=0.1、peer 边长 0.65。真实 A 在 t=0.05 触边，B 在 t=0.075 追上；先把 A 终点压成 10、全段改成速度 1，会把追尾提前到 t=0.05。终点可能相同，碰撞时间仍然错误。
- `_candidate_span` 的逐坐标 peer/墙修正会破坏圆内性：从 (10,0) 到约 (9.99950004,0.09999500) 的弦合法，但若另一约束撤掉 x 内收，改成 (10,0.09999500) 就越界。因此圆证书必须参与整个候选固定点循环。

## 推荐实现步骤

1. **只读边界快照。** ActorSpace 提供由已验证 world/layer 派生的圆心、R、r 与完整 layer_key；controller 将它作为可信求解参数传入，不让 RPC 提供半径或裁切结果。保留原 preview 内容、serial/revision、新鲜度和提交票据格式。walk、dodge 使用同一路径；以后服务端授权的 forced 位移也必须复用它，不在此新增强制位移玩法或客户端权限。

2. **内部直线先精确找第一次出圆时间。** 用标量 double 的点积求 `|p+t*v|²=ρ²` 的出圆根，与所有角色的原 segment/dodge 边界共同取最早时间。采用避免消减误差的二次根分支，显式处理零速、圆上外向/切向的零根、圆上内向的后续正根。所有角色暂定同一时间前缀，native 墙查询和 relative AABB CCD 都在这个前缀上比较，更早的墙/peer 事件仍优先。没有人被逐个预移动，未到第一次圆接触前不弯折原运动。

3. **触边后生成正时长的合法弦候选。** 记录求解器内的临时圆接触状态；在当前径向 n 上仅去掉意图速度的正外向分量。对保留的切向速度 vt，取共同有限时长 h，构造 `q=投影到闭圆(p+h*vt)`，将 p→q 作为真实待扫掠弦。例如上述反例变为约 (9.99950004,0.09999500)，非零切向可前进；纯外向变成静止但正常消费 h；合法内向则退出贴边模式。投影的是未提交候选，绝不直接移动角色。两端在闭圆内即可证明整条直弦在圆内，但不能证明无墙或无 peer。

4. **全体同时间 CCD，不是逐人裁切后提交。** 每个候选弦都有同一个 h；对这些实际弦重新执行全体 peer relative CCD 和 native 环境 sweep，以最早事件推进所有角色。若事件提前，首先只接受本轮已扫掠弦的同时间前缀；在该事件之后才按真实剩余时间重建候选并全体重扫，不能把旧命中比例套到新弦上。圆弦的法向内收只是曲率表示，不能把它累积成下一段玩家输入方向。保留独立的原意图与墙/peer 约束状态；人工曲率分段不得无条件恢复已被墙/peer 去掉的速度。

5. **圆内认证加入现有候选固定点。** 任一 peer、环境或浮点拟合改动候选后，重新检查圆、位移预算、精确 query_motion 重构、所有连续 peer 相对路径及 native 墙路径。圆修正也必须触发同样的全体重查。只能在整轮候选不再改变且所有证书通过时接受。不能只靠最终 `prepare_positions` 发现出界，更不能 endpoint clamp 后漏扫新路径。边界不再作为普通“切线零时 hit”反复反馈；真实墙的零时接触仍由现有约束处理。

6. **数值与有限工作量。** `full_environment_body_inside` 及候选认证统一以原 Vector2 分量先转 double，再检查距离平方≤(R−r)²，不能依赖 binary32 的 Vector2.length，也不能增加出界 epsilon。目标写回 binary32 后仍需同一证书；允许对未提交弦端做有限 ULP 的向圆内舍入，再重验位移预算与全部路径。不得修复/推移输入起点。无法表示、未知区域或迭代耗尽整体失败，无部分位置/时钟提交。

   对贴边弦给出显式曲率误差预算，而非固定“无限细分”：建议初始评估最大弦弓高 δ=1e−4 cell，且 δ<ρ；弦长上限 `2*sqrt(2*ρ*δ−δ²)`，再以当前受限速度给出 h 上界。这个预算只约束圆弧的向内近似误差，不允许任何向外穿透，也不代表整条轨迹相对连续物理解的全局误差保证。每 tick 最多 256 个新增共同曲率区间作为待验证的技术起点，并保留原接触/候选迭代上限。所有 segment、死亡与 dodge 结束时刻仍必须精确分段；不跳过剩余时间，不把数值分段当资源结算或输入边界。贴边是有界近似，不能宣称解析圆弧精度。

7. **ActorSpace 查询边界。** 求解器先把 native 查询限制在全圆合法的实际候选前缀；adapter 对越界请求继续作为防御性错误处理，不再接到正常外向的完整原始段。未知区域/地下未生成岩层继续失败关闭。还须证明整条 swept body 位于已 materialize 的覆盖域：当前 `_covered` 只测首尾，在多个不连通矩形覆盖下不能推出中间已生成。可在本步保守要求整个直弦扫掠包络落在同一个已知矩形内，不把跨空隙当空气。

8. **提交不变。** 所有曲率子步只改 detached 工作副本并写实际 trajectory；整 tick 仅调用一次既有 `commit_actor_preview`。仍按 prepare → 模型 commit → native target submit，下一物理帧验证 target 应用；票据单用、stale 拒绝、fatal 后禁止广播/保存均不变。

## 另一方案（本轮不选）

精确解析圆弧/受约束圆周 ODE，再对圆弧对圆弧、圆弧对直线做 conservative advancement CCD。曲率时序更准确，但现有 Geometry 和 native body_test_motion 都只证明直线；必须新增曲线相对距离界及 native 分段证书。改动与验证面明显大于本轮有限接线，不能用“只验弧两端”简化。

## 最小回归组（均待另获执行窗口）

1. 上述内部 A/B 追尾反例：断言真实首碰 t=0.05、追尾 t=0.075，并验全轨迹；加入跨 16/32/256 坐标舍入点。
2. 圆上纯外向/纯切向/斜外向/内向四向：外向停止、切向连续有进展、内向自由，无零时死循环；整 tick 时钟推进正确。
3. walk、跨边 dodge 与服务端强制位移输入夹具共用路径；dodge 成本/冷却不退还，dodge_end_position 不混入后续 walk。
4. 同时两人贴圆相向、第三人被夹与同深度不同 body/world：每个实际共同弦用独立连续 AABB oracle 验无交叠、无推人加速，层隔离不变。
5. 圆边邻墙/窄角：墙先于圆、圆先于墙及近同时事件；墙挡住合法弦的中段时必须停止/滑动，不能凭圆内终点穿过。
6. peer 改掉弦的径向内收、斜法线和 ULP 写回：强制重做圆证书/全体扫掠，严格不出界且实际位移不超预算。
7. 未知地下、覆盖矩形中间空隙、坏圆/坏起点、限次耗尽与后续 callback 失败：整批无部分模型/时钟/native target；stale/重放票据仍拒绝。
8. 同输入拆 tick 的收敛/误差与长期沿圆滑动：只允许文档化数值近似误差，不逐步扩大地图、不累积额外位移或退化成原地停住。

本评审不声称新增圆边界已实现或通过；既有三端 GUI 结果也不能替代这些新场景。

## 2026-10-06 接线源码检查点（未执行新测试）

ActorJointSolver 新增第5参 `circle_boundaries: Variant = null`。null 保留原路径；字典必须覆盖每个活动角色的完整层键，且 body_radius 与可信 expected_half_extent 相等。圆模式保存独立意图、每个真实 preview 区间的墙/peer 约束和临时贴圆状态，人工曲率区间不重置这些约束。首次圆 TOI 截断共同时间；之后才生成弦，全体 native 查询和 peer CCD 使用实际、可重构的弦位移。

原 `_candidate_span` 增加可选圆证书。peer/墙/浮点拟合改动候选后重复验证；若修正后的线出圆，仅以共同标量比例缩短并朝原start舍入（最多64次保守退让，允许最终start零位移），不重新生成已被约束删掉的弦分量。径向投影只允许出现在最初贴圆弦构造；首次TOI目标、主循环目标和已受墙/peer约束的候选均禁止再径向投影。允许认证后的零位移消耗正时长，禁止零时假前进。圆模式保留全部 preview/dodge 时间边界及最终位移预算；成功仍只返回原可提交 positions 格式，失败不返回部分轨迹。

固定弓高上限 1e−4（半径更小时取更严格值）控制理想弦步长；最多256曲率区间，另受既有事件/约束次数限制。它不是任意精度圆弧或全局误差保证；实际 binary32 端点仍须严格在圆内，并经原生查询与全体连续相对轨迹证书。不能拿理想弓高代替这些证书。

另含 circle-enabled 的远离圆边跟随回归，跨16/32的binary32量化点。原严格全轨迹/速度预算断言不变，首碰时间另行检查；新分支多出的motion/duration往返与legacy端点按最多4个对应binary32 ULP比较并输出实际差值。这是待执行的精度约束，不是已观察到的差异或放宽碰撞/速度判据。
