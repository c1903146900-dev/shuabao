## First source step

1. On an actual F pressed edge, the play client freshly samples the current pointer through the current view inverse. Invalid/outside-view input suppresses that press. It must not reuse cached last-valid aim. Release bookkeeping and all other sampler controls remain intact
2. A pure server-owned selector reads verified layout.connections, the current authoritative actor, accepted aim and table-derived interaction range. It filters by the complete layer identity, hit-tests the actual3×3body for that endpoint, and checks inclusive distance to the endpoint interaction point. No nearest-entry fallback, resource target, client-specifiedtargetID or outcome is accepted
3. Cell-center through Address.cell_center is an explicit technical mapping of existing endpoint.cell; the originals define the distance measurement but do not prescribe a subcell natural-entry interaction point. This creates no extra anchor
4. Controller calls the selector only for a newly accepted interaction_requested edge. Duplicate/held/released requests cannot dispatch another interaction. Selection and rejection causes are internal admission/diagnostic outcomes. Even a selected valid entry remains explicitly unsupported for transfer until required collision and transaction work exists
5. Keep positions, body spaces, identity, resources, cooldowns, input generation, save schema and wire protocol unchanged. Fsend, selected target, admission cursor and refusal output are not successful layer transfer

Targeted source tests should cover fresh pointer versus stale aim, invalid pointer press suppression and release, exact range boundary, miss/no nearest fallback, full-layer mismatch, malformed/ambiguous connection records, no resource targets, no mutation, and no duplicate redispatch. Runtime tests require a new allocated window.
