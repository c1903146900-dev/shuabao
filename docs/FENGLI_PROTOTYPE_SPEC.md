# 风厉：单人战斗原型规格

版本：2026-09-30。面向 shuabao 的首英雄原型；本文件是设计提取，不表示功能已实现或测试通过。

## 1. 适用版本与实现边界

来源为从“这样吧，我们就做一个纯粹的刷宝游戏”开始的最终讨论，风厉原案及紧接着的修订、后续纯数值升级规则，以及9月30日设计基线。最新明确修订优先。历史助手的示例数值不等于用户定值。

- 定位：使用长剑的刺客型战士，高机动、击杀连续作战、普攻/攻速构筑、残血反打
- 目标体验：3D俯视高速ACT，最终1至5人合作；先做风厉单人战斗切片
- 操作：WASD移动，鼠标左键普攻，Shift冲刺，Q/E/R主动技能，另有一个被动槽
- Q三选一、E三选一、R二选一、被动三选一，共11个候选；各槽可暂不学习，各技能不能强制依赖另一个技能才能使用
- **18级、18点：被动学习+两次升级共3点；Q、E各学习+四次升级共5点；R学习1点，两次升级各2点，共5点。没有任何额外技能点来源**
- 账本以1级1点、此后每级1点实现，总计18；R沿用6级可学习。R后两级门槛尚未给定
- **升级只有数值成长，没有A/B/C/D机制分支。**学习时即获得完整基础机制；机制改造归海克斯，不自动并入技能本体
- 以下技能数值为已知基础档；Q/E五档、R三档新数值表尚不完整，可按现有授权补测试初值，但须单独标明，不能称作原案已确认值
- 不要求第一轮把装备、海克斯、四幕和联机全部实现。未实现内容需清楚列出，不能以简化原型永久删除已定核心机制

## 2. 普攻与Shift

### 普攻
- 长剑近战普攻，能与攻速、暴击、吸血及R2普攻次数计数联动
- 未确认：基础AD/生命/移速/攻速、普攻倍率、命中形状/距离、攻击移动限制、动作时长、前后摇与取消窗口
- 三段普攻曾作为制作建议出现，并非风厉已确认的第三击特效或额外倍率；不可移植其他样板英雄的怒气、第三击增伤等机制

### Shift
- 固定冲刺槽，不占Q/E/R选择和18点技能预算
- 现有讨论采用普通位移冲刺，不默认额外的“冲刺攻击”；冲刺后衔接普攻可作为手感实现方向
- 未确认：基础距离、时长、CD、无敌或减伤的具体方案/帧窗、穿敌与碰墙、方向优先级、取消窗口、攻击缓存
- E3明确使Shift冷却减少50%；如何与全局冷却缩减叠算、怎样影响正在转的Shift CD，尚需定义

## 3. Q技能：三选一

### Q1：短矩形突刺
- 向前方较短矩形刺出一剑；碰到的所有敌人各受1.2AD普通伤害，同一次不对同一敌人重复叠伤
- 基础CD 5秒；命中敌人减少该技能30%冷却
- 技能造成击杀：刷新CD并强化下一次Q1，长度与伤害每层提高30%，最多4层；继续击杀保持上限
- 一次Q1没有造成击杀，强化回到基础，但命中减CD仍有效
- 需补行为定义：强化按基础加算还是复利（讨论建议加算、4层+120%，不是另行确认的专属公式）；减的是完整CD还是剩余CD；同次命中/击杀多个目标如何限次；判定宽限关闭后才确定“未击杀”；强化层是否跨房保留

### Q2：连续锁敌突袭
- 首次选定中距离内一个敌人，突刺造成1.5AD普通伤害；再从当前目标附近小范围寻找后续合法敌人，最多共4次
- 每次突袭约0.2秒；整段期间不可选中、免疫伤害，不能施放技能；结束落在最后目标身后
- 全段结束后开始CD，基础12秒；无后续合法目标时结束
- 原文后续目标出现“有被本轮次技能伤害的敌人”的疑似漏字，与旧“允许二次打同敌”的分支矛盾。现有解释倾向基础只找本轮未打过的敌人，必须在实现记录中明示此解释，不能暗中做单目标四连击
- 需补：搜索/初始范围、目标排序、目标死亡和落点被墙阻挡时的回退、整段控制免疫与移动输入行为

### Q3：长矩形剑气
- 向前斩出较长矩形剑气，对碰到的所有敌人造成0.8AD普通伤害，沿剑气方向击退一段距离
- 基础CD 11秒
- 基础没有双充能或额外眩晕；那些属于已废止的机制分支、可另作海克斯候选
- 需补：长度/宽度/速度、击退距离、每目标限次；Boss击退转硬直的量

## 4. E技能：三选一

### E1：追踪匕首与二段穿刺
- 选定较大圆形范围内一个敌人投出追踪匕首；命中造成1.5AD普通伤害，标记5秒。目标提前死亡则可能无法命中
- 标记存在期间可以再次释放：选择标记目标周围小圆内任意落点，瞬间穿刺过去；沿途所有命中敌人受0.5AD普通伤害，随后清除标记
- 基础CD 18秒；依“结束后计CD”规则，在二段使用或标记结束后开始计时
- 基础没有命中眩晕、对标记增伤、落地攻速加成
- 需补：两种范围、飞行速度、穿刺宽度/穿墙边界、目标死亡/匕首失效/标记丢失时的CD开始时刻

### E2：旋斩与瞬移
- 原地附近小圆旋转一圈，对所有敌人造成0.7AD普通伤害；旋转时可以移动
- 随后向指针位置瞬移，超过最大距离则限制在最大距离
- 若落点附近小圆仍有敌人，获得1秒短暂无敌
- 基础CD 17秒
- 最大瞬移距离原文为“XX”，未给定；旋斩半径、落点检测半径、旋转时长、落点合法性、无敌开始帧均待补
- 不自带多圈、返回虚影或落地再旋转；旧多圈分支的每圈减伤已从0.2AD修为0.1AD，但仅作历史海克斯候选，不进入普通升级

### E3：超载
- 基础持续7秒：移速+30%、攻速+30%、韧性+30%
- 普攻额外造成25%真实伤害；Shift冷却减少50%
- 期间每次符合条件的击杀令**持续时间延长1.5秒**
- 基础CD 32秒，超载结束后才开始计算
- 不自带免疫一次致命伤、额外暴击或吸血；这些不是基础机制
- 需补：额外真伤按哪一项普攻伤害取25%、暴击是否影响它、是否触发吸血/攻击特效；参与击杀口径；是否存在持续时间上限（未确认，不能自行声称有上限）

## 5. 被动：三选一，均为三档

### 被动1：普攻吸血
- 机制：普通攻击附带吸血
- 旧四档为2/4/6/8%；最新被动只有三档，尚未确认保留哪三档或重排后的表
- 不自动将其扩展为所有技能吸血

### 被动2：残血反打
- 生命从至少10%下降到**大于0且低于10%**时，重置Q和E，并恢复一定比例最大生命值；受自身冷却限制
- 一击直接打至0生命不能触发救命或复活；用户已接受此修正
- 旧四档恢复7/11/15/19%最大生命，CD120/100/80/60秒；新三档表尚未确认
- 需补：Q/E处于施法、二段或持续状态时“重置”的精确语义，避免重复超载、取消二段或产生两份状态；被动CD的全局CDR适用性

### 被动3：击杀成长
- 最新用户修订为每击杀10/7/5名敌人，攻击力永久+1；恰好可对应最新三档
- “永久”按本局成长理解，不应直接写入局外基础属性；这应在原型说明中明示
- 需补：击杀/参与击杀口径、升级时未满计数是否继承、每次累计阈值扣除方式；不擅加成长上限

## 6. R技能：二选一

### R1：巨圆乱剑与斩杀
- 在**巨大圆形范围**内对所有敌人造成1.5AD普通伤害；伤害结算后，敌人生命低于5%则直接斩杀
- 动画为高速多次穿刺/乱剑；伤害按范围目标结算，不依赖角色视觉上是否穿过该敌人
- 基础CD 130秒；演出期间施法者无敌，并采用统一大招世界减速规则
- 圆形替代旧“屏幕内”，也否定助手提议的“整个竞技场”。中心与半径未给定
- 不自带7%斩杀、普攻减R CD或释放回血；这些不能作为普通升级的额外机制
- Boss斩杀边界需显式列明；原文没有写Boss免疫，不能静默删掉对Boss的效果

### R2：累计普攻骨钉
- 向前长矩形发射骨钉，对范围内敌人造成伤害；每根为**0.5AD + 目标最大生命值的0.25%**普通伤害
- 命中减速30%，持续3秒；多根伤害可叠加，减速幅度不叠加
- 基础共3次投掷，每次后必须在3秒内再次施放才能续下一次
- 首轮1根；第二轮起，每轮数量 = 1 + 从首轮投出后累计到本轮的普通攻击次数
- **每轮后不清零普攻累计数；没有已确认的骨钉数上限。**用户在风险提示后只下调最大生命倍率，并明确其他不变
- 基础CD 130秒，按总规则在三轮结束或续施窗口结束后开始计时
- 不自带第四轮、额外每轮基础骨钉或额外真伤
- 需补：普攻计数按动作开始/完成/命中、空挥是否算；每根几何与重复命中方式；窗口边界、减速刷新方式；多次投掷与大招演出/时间流速的关系
- Boss百分比伤害没有已确认的单独削减或上限，若需平衡必须显式提出

## 7. 原型必须遵守的通用战斗规则

- 只有12项通用属性：AD、AP、攻速、暴击率、冷却缩减、生命、防御、移速、吸血、韧性、穿甲、基础生命恢复；风厉没有已确认的额外怒气或蓝量资源
- 无特别声明的伤害为普通伤害；AD/AP是缩放系数，不拆物防/魔抗；真伤与普通伤害分开结算
- 百分比属性按基础值加算；CDR上限65%、韧性100%、常规攻速2.5次/秒，移速不做收益递减。没有为风厉登记突破攻速上限的基础例外
- 统一防御；普攻可暴击，技能只有明确标记才可暴击；范围吸血折算。防御公式100/(100+max(0,防御−穿甲))、暴击175%、范围吸血40%、持续伤害25%是现有测试初值，不是不可调整定值
- 无敌免疫伤害与控制；不可选中阻止新的直接锁定，不自动等同范围伤害免疫。Q2另有明确免伤要求，不能仅加不可选中标志
- 100%韧性免疫相应普通时间型控制，不保留0.1秒最低控制；强制位移另算，Boss普通控制转硬直，转换量待补
- 技能原则上施法/持续/可重施阶段结束后才进入CD；逐技能定义，不把E3的32秒在开技能时就转起来
- 击杀有短判定宽限，技能击杀与参与击杀要区分。约0.2秒仅测试初值；Q1不能无条件改成普通助攻刷新，E3/P3参与击杀的具体口径待补
- 战斗结束立即冻结生命、冷却、充能及需保留状态；安全等待不回血、不转CD，明确恢复效果例外。基础生命恢复仅战斗中生效
- 大招演出施法者无敌；世界减速只有一层，同时放大的施法者都进入正常速度演出通道，不相乘减速；CD/Buff等按战斗世界时间推进。减速倍率、演出时长待补
- 战斗中学技能/升级不暂停；下一场前可撤销刚投入的新点数，旧技能重配只在训练节点；不能通过撤销/洗点刷新生命和CD
- 真死亡扣当前已获得经验进度30%，不扣钱、不降级、不回收技能；倒地救起不罚，单人每局一次自救。具体倒地/自救时序待补
- 最终联机无友伤、无玩家碰撞，个人钱包/装备；人数只改变怪物血量、攻击、数量，不改变技能模式

## 8. 冲突与未定项总表

1. **点数与等级**：旧15级/特殊17级/约22点/技能全满23点全部作废。旧装备任务、局外、英雄、海克斯加技能点全部删除
2. **升级**：旧分支整套作废；不能把分支全部免费塞进基础技能，也不能换成升级时自动获得同样机制。历史Q1六档示例不适用于新五档，不是最终数值表
3. **被动档数**：P1/P2四档需改为三档；P3最新10/7/5可直接作为三档候选对应，旧每5杀基础版本不再使用
4. **已明确修正**：E3击杀延长持续时间，不延长CD；P2不是致命伤免死；R1巨大圆而非屏幕/全场；R2最大生命倍率0.25%而非0.5%，累计规则保留
5. **文字冲突**：Q2后续目标疑似漏“未”字，基础重复攻击同目标规则需明确；E2旧分支0.1AD修正不代表基础旋斩变成0.1AD
6. **空间与动作**：所有“短/长/中/大/小”缺世界单位，E2甚至为XX；普攻、Shift、技能时长/取消/碰撞与镜头尚需完整手感数据
7. **关键交互**：Q1叠层/宽限及跨房；P2对活动技能重置；E3真伤基准/无限续时边界；R2计数事件、时钟、Boss百分比伤害；R1Boss斩杀均不得静默改写
8. **战后状态**：生命/CD冻结已定；Q1层、E1标记、E3剩余Buff、R2未用轮次、被动计数等须列逐项保留/清理表。不能把尚未确认的“一切短期状态清除”当成用户明确规则

## 9. 首轮建议验收点（实现建议，不新增设计）

- 能进入可操作的3D竞技场，移动/长剑攻击/冲刺反馈清楚，至少普通怪、精英、测试Boss可验证伤害与控制
- 11项候选可单独验证；选定槽位独立可用；18点越界分配被拒绝，R6级前不可学习，无机制分支UI
- Q1命中退款、击杀刷新/4层封顶/未杀归零；Q2不超过4次且全程免伤；E1二段及过期；E2有敌落点无敌；E3击杀续时、结束后计CD
- P2非致命低血触发、直接致命不触发；P3按10/7/5累积；P1/P2测试档值须公开标为新初值
- R1按圆判定；R2以已知普攻数断言每轮骨钉数，确保不清零、不擅自封顶
- 战后等待生命/CD不变；大招结束、死亡和房间结束都正确退出演出/慢动作；无敌、真伤、暴击、吸血、100%韧性各有测试
- 交付记录写明实现范围、测试初值、实际通过/未执行测试、仍需确认的机制边界
