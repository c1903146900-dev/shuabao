# 单房间整合 checkpoint 1

此 checkpoint 使用真实战斗模型、第三轮骨骼美术和首版 HUD，默认入口为 `scenes/integration/room.tscn`。它是可操作的单人试炼，不是完整游戏、联机版或正式平衡版本。战斗源为 `6ae6dd982d7b5a1103f5fa77bb0b6bee80948eb4`，美术源为 `69d58417c157b5855ce50703916318973080e771`。

## 如何体验

打开 Godot 项目后 F6 运行整合场景，或 F5 运行默认入口。战前按 K，选择 Q/E/被动的一项并投入初始1点，然后关闭面板点击“进入试炼”。WASD 移动，鼠标瞄准、按住左键普攻，Q/E/R释放已学技能，Shift冲刺，K修习。倒地结算关闭后空格自救一次；关闭结算后 F5 新开一局。不要把 F5 当读档：新开会清空本局账本。

## 权威与范围

`scripts/integration/ledger_bridge.gd` 仅适配旧战斗账本接口，唯一技能点权威为现有 progression/model.gd，读取 confirmed_rules.json。移除默认6级战斗 fixture 的技能初值，实际从1级1点开始，未学习槽位不可施放。没有采用成长测试 fixture 的经验曲线、药品策略或额外技能点。当前经验、金币奖励、商店、海克斯、锻体、存档与训练洗点未接入；UI明确显示奖励待接入，不能宣称完整成长循环。旧 HUD“撤销本场”文字与真实单笔撤销不符，因此此 checkpoint 禁用该按钮，等待 UI 任务控制器交付。

战斗进行时打开面板不暂停模拟；整合层清除攻击和移动锁存，鼠标不会通过原竞技场的全局按键轮询穿透面板。按键释放和窗口失焦独立清理。引擎输入系统和真实窗口输入须分别验证，不能用模拟器直接扣血作为击杀证据。

敌人 windup/release 以战斗状态的剩余时间采样，命中前摇分别0.85/1.00/1.35秒；伤害不读动画。风厉跑动按位移/2.0、敌人步行按位移/1.15播放。死后动画可以完成，HP/CD和战斗时钟保持逻辑冻结。骨骼美术和警示已接入，地面仍使用战斗 arena 原有白盒；密集怪物血字与轮廓有遮挡，需后续画面迭代。
