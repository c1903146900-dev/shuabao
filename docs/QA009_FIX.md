# QA009：取消封房 Q2 链并隔离跨房目标上下文

来源：[独立 QA b593127](https://github.com/c1903146900-dev/shuabao/blob/b593127788fcd3c8198be8039bf7abd40cbae662/docs/QA_AUDIT.md)。在表现主线的实际战斗源码上复现，不能用旧 QA002 的 R1 修复代替。

默认 64HP 小怪经普攻降至32，再 E1→Q2，E1致命自然封房；旧 Q2 的下一次寻敌会选中新房目标。原有 pending 房间校验没有覆盖 hero.cast_state.q2，这正是遗漏的独立路径。

修复：

- Q2 封房即正常结束链、撤销不可选中并结算既有 Q 冷却，不再将攻击链留给下房。世界/HP/CD继续按原规则战后冻结。
- Q2 和 E1 目标状态保存模拟实例、房间ID、房间代次。每次执行前校验；Q2 伤害及命中事件回调之后再次确认当前链仍有效，再允许选择下一目标。无效上下文不能把英雄传送回旧房落点。
- E1 保留同房冻结规则；敌人集合换房时结束旧目标并结算既有 E 冷却。旧上下文即使碰到复用目标ID也不能击中新房。
- R2 普攻完成计数回调也携带并验证当前房间上下文；旧房完成事件不能增加投数，当前房完成事件仍只计一次。
- E2 延迟位移、E3持续buff、R2剩余投掷与累计计数保持原保留策略；保留这些状态不会自动伤害新房，合法新输入仍能继续 R2。

没有改变伤害、目标几何、Q2同房最多四次不重复命中、E1正常追踪/标记、P2或等级技能点规则。更新的 post_room 策略显式列出 Q2/E1 边界，旧“Q2链一律冻结保留”的测试文字不再作为正确规则。
