刷宝 · 风厉 Windows 最小试玩切片

这是供判断战斗方向的单人原型，不是完整游戏。只有风厉与两种重复房间布局；未实现四幕流程、联机、保存与完整内容。

启动
1. 将 ZIP 完整解压到普通文件夹。
2. 保持 shuabao-smoke.exe 与 shuabao-smoke.pck 在同一目录。
3. 双击 shuabao-smoke.exe。不要在 ZIP 预览窗口中直接运行。
4. 首次有1个技能点，可按K学Q；关闭面板后按Enter进入第一房。

操作
WASD：移动；鼠标：指向；按住左键：普攻。
Q / E / R：使用已学习技能；Shift：冲刺。
K：技能修习；P：行装和补给；Esc：关闭面板。
准备/胜利时Enter：进入下一房。安全阶段可以学习、升级、购物。
倒地后先关结算，再按空格自救一次；真死亡后F5在原房续战，保留账本和冷却。
右侧“音效：开/关”按钮：静音。

建议试5分钟
学Q → 移动、普攻和Q清房 → 用赚到的技能点升级 → 进入第二房。
主要判断移动与攻击手感、预警是否看得懂、界面是否妨碍操作。可提供屏幕录像或问题截图反馈。

本包状态与限制
- Windows x86_64测试包，未在Windows实机执行；当前只完成PE/PCK验证、Linux无头启动和云端Linux窗口玩法检查，不保证所有Windows硬件兼容。
- QA009的Q2跨房残留伤害已修复（5bac39160a62faa24eb179fc8e78afaf66fad2d5），新增68项、原战斗364项、邻接35项及54组rank1组合测试通过；独立QA最终复验另行记录。
