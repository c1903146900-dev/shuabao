# OS 连续游玩预览

`two-room-os-source.mp4` 来自源码提交 `53a5c1a5aa7dee2ee2ee45b4649b67b368d869c7` 的真实 1280×720 X11 窗口。32.067 秒连续 ffmpeg x11grab，自动化 XTest 键鼠：学习 Q、进入第一房、移动/攻击/Q、胜利、用获得的点升级 Q、第二房战斗并结算。实际查看第二房 3/3、等级3、金币900的画面；没有直接设置角色状态。

不是截图拼接。视频无音轨，不代表音质验收。它是**源码版预览，不是最终导出包验收**。记录、视频 SHA256 和 OS 操作时间表在同名 JSON；图片只是结算检查证据，不作为视频源。
