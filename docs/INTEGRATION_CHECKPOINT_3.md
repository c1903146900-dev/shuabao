# 药品与最小数值构筑 checkpoint 3

基于 `a294d0420f5b5a23027d94755a9f78509b6929b4` 的两种房间循环；不含后续美术或音效分支。默认入口仍为 `scenes/integration/room.tscn`。本阶段只接药品、AD/AS/最大生命/CDR装备与无技能依赖的纯数值海克斯。目录数值是可调原型初值，非历史确认定稿。

## 玩家操作及实验策略

P打开安全商店，六槽行装页提供“使用”和“出售”。战斗、倒地、真死亡阶段不能用药；胜利后可以主动用药，自然回血与所有冷却仍冻结。满血拒绝且不消耗；超出最大生命的治疗丢弃。普通血瓶每份75金、恢复18%最大生命，最多持有5份，实验策略为5份堆1槽。特殊药每份140金、恢复30%，每份占槽，本房最多使用2次；仅进入新房间重置使用计数，不免费补充库存。普通/特殊持有互斥，且本房已用一类后不能出售再换另一类使用。

“每关”暂映射当前战斗房、堆叠方式以及本房使用互斥均为显式实验策略，不是补写已批准事实。F5仍是同房续战，不调用enter_level，因此不刷新用药计数。模型的六槽、普通5份、特殊2次和互斥校验保留；失败不扣道具、不加生命、不动冷却。

## 消费者与事务

`consumers.gd` 是同步、无await的本地协调层：先验证真实战斗阶段、存活、生命缺口、物品与效果，再原子调用模型扣除物品，成功后仅增加真实HP。请求ID/物品UID校验及模型receipt阻止重复治疗，包括更换协调器后的重放。用药清除交易撤销记录，不能撤销消费拿回药品。

仅声明六个能力：`stats.v1`、`stat.AD.v1`、`stat.attack_speed.v1`、`stat.max_hp.v1`、`stat.cooldown_reduction.v1`、`recovery.v1`。没有全量flag。四件组件和两类药品可用；其他装备效果缺少消费者时拒绝购买。保留完整12属性目录与原有caps；攻速最终不超过2.5，CDR不超过65%，韧性上限100%仍保留但不开放其数值构筑hook。

| 消费端 | 实际接法 | 不变量 |
|---|---|---|
| AD | 基础32加聚合AD，实际普攻/技能读取hero.ad() | 不逐帧累加，不改既有CD |
| AS | 基础1.7乘(1+属性比例)，用于真实普攻间隔 | 受2.5上限约束，不重置已开始的攻击CD |
| HP | 基础240加聚合最大生命，真实伤害/治疗使用该上限 | 增加上限不回血；降低上限只向下截断HP，不回填 |
| CDR | 聚合比例写入战斗cdr，新施放按实际比例计算 | 买卖/撤销/升级不重算正在倒计时的CD |

海克斯只开放7个无技能依赖的纯AD/AS/HP/CDR项。依赖技能的数值项和19个机制草案仍关闭；没有把未知休眠政策当已定事实。小候选池在前三格抽选时保留最后一个可用英雄项给第四格；候选不足时原子拒绝，不能把未实现效果塞入池中。此有限池不是完整四幕构筑内容。

## 行动回执与状态

Q/E/R/Shift在冻结时也返回真实encounter_frozen；失败提示映射真实reason。E3持续、R2演出锁定/重施窗口、战后冻结来自战斗状态，而非固定“就绪”；有剩余CD时显示实际CD。动作动画覆盖与GLB闪白仍是下一阶段，不因状态文字接通而标记完成。

## 验证及证据边界

MCP实际执行initialize/tools/list/应用查询、脚本创建/验证、运行、InputEvent和截图。自然流程只靠击杀赚金币，不直接加经验、金币或关AI：重复两个布阵到第7房，买生命/药品/攻速/CDR，真实治疗、满血拒绝、使用后重放、继续战斗并选择数值海克斯。第7房表示重复布阵，不是新增7种房间。

已观测：最大生命240→340，买入时HP不变；普通药223.185→284.385（+61.2），再用药到340，满血请求不耗药；AS1.7→1.904，新冲刺CD3.2→3.008。独立受控战斗/模型测试覆盖特殊治疗72、第三次拒绝、跨房重置、六槽、普通5份、换药互斥、重复请求、HP买卖撤销、AS/CDR上限及E3/R2状态。受控测试通过MCP调用实际模拟器，不能冒充自然玩家过程；输入仍是Godot InputEvent，不是OS级窗口输入。

开发中保留两类失败事实：药品说明百分号格式错误及提示字典重复键已修复；首轮输入测试的滚动目标定位不稳定，改为显式滚入可见区域后用真实鼠标事件点击，并核对回执。没有用直接模型购买替代GUI验收。
