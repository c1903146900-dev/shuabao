# 晏归舟：回帆与不尽规则

**实现状态：未验收。** 本文记录已确认的玩法与验收要求，不代表机制、视觉或正式获取流程已经通过验证。

## 基础技能约束

H09「回帆」与 H10「不尽」均依附 E2「孤帆远影」。保留基础技能的施放、航行、登舟传送、登舟爆发和未登舟终点爆发规则。

- 有效放舟时开始基础冷却；登舟、返航和诱饵结束不得重复开始冷却或重复消耗。
- 舟可穿过实体墙，但英雄登舟落点必须合法。非法落点拒绝本次登舟，保留当前舟，不将英雄挪至替代落点。
- 舟到房间边界停车，原航程时钟继续；不反弹、不提前爆炸、不延长存在时间。
- 停车后仍按原登舟窗口及精确落点合法性决定能否登舟。

## H09「回帆」

登舟后，小舟不消失，而是沿实际已航行路线反向返回。

| 参数 | 数值 |
| --- | --- |
| 返航速度 | 6 米/秒 |
| 路径宽度 | 1.4 米 |
| 普通伤害 | 60 + 60% AP |
| 每名敌人返航命中上限 | 1 次 |

原登舟传送和登舟爆发保留。英雄留在合法登舟落点，只有舟返航，不增加持续乘舟玩法。

返航逐段反转已完成的实际路线，不能直接连接起终点代替原路线，也不能包含尚未航行的路段或界外路线。暂停恢复不得重置命中记录或重复结算已提交伤害。

## H10「不尽」

完整航行结束且未登舟时，在实际终点留下诱敌墨舟，持续 **3 秒**，嘲讽半径 **5 米**。原未登舟终点爆发延后到诱敌墨舟正常结束时触发一次。

边界停车不等于完整航行结束；必须等原航程时限到达，才能进入诱饵阶段。诱饵阶段不重新开放登舟窗口。不新增诱饵生命值或可摧毁机制。

### 嘲讽权限

| 敌人类别 | 是否受该诱饵嘲讽 |
| --- | --- |
| 普通怪 | 是 |
| 精英怪 | 是 |
| Boss | 否，免疫 |

权限必须作用于实际移动与新攻击的选目标路径，不能仅改变状态标签。嘲讽结束或被清理后，恢复原正常目标查询。

已提交的攻击、预警与弹体继续使用原碰撞管线，不追溯改变目标。Boss保持原目标、技能和阶段行为；本规则不改变其他控制效果的权限。

## 双持与清理

同时持有两项海克斯时，分支互斥：

- 合法登舟：原登舟传送与爆发后进入回帆，不生成诱敌墨舟。
- 完整未登舟：进入不尽，不额外触发回帆。

同次施法只允许一次消耗、一次冷却起算、一次释放事件及一次正常终结。返航或诱饵期间发生施法者死亡、取消或换房时，清理该舟及其待处理工作和目标覆盖，不补发终点爆发或 P1 结算。清理不应删除其他来源的合法状态。

## P1「计白当黑」结算契约

P1按一次完整施法判定单目标，不能逐段重复支付。冷却返还比例按P1等级为 **5% / 8% / 14% / 23%**，基数为实际结算当刻的剩余冷却。

E2原技能合法伤害集合包括去程伤害、登舟爆发和未登舟终点爆发；伤害必须属于同次施法、同一舟与当前房间实例。H09生成的返航伤害不加入该原技能集合，也不能递归触发P1。

- 原技能合法集合只命中一名敌人：整招可靠终结、伤害结算完毕后，按当刻剩余冷却返还一次。
- 原技能合法集合命中多名敌人：不满足单目标退款条件。
- 仅被返航命中的新敌人，不扩张原技能集合；仍须核对其确实没有受到原技能伤害。
- P1未学时，不产生P1退款或结算记录。
- 剩余冷却为0时保持0，不生成未来额度，不重新开始冷却。

无回帆时，登舟完成可能立即触发P1退款，所以登舟前后冷却数值不一定相同。有回帆时，不能为保持相同退款时刻而提前终结整招；有不尽时，必须等延后的原终点爆发完成。返还造成的冷却减少不等于冷却被重新启动。

## 待验证清单

以下项目均须取得实际运行证据，不能用规则文档或数值推导代替。

- 四种持有组合：均不持有、仅回帆、仅不尽、双持；合法登舟和完整未登舟分支正确互斥。
- 实际边界停车、原寿命不变、非法登舟拒绝且保留原舟；登舟点同时符合英雄体型与动态占位约束。
- 回帆严格反转实际路线，英雄不随返航移动，每敌最多一次；暂停恢复无漏段、重复伤害或重复终结。
- 不尽持续3秒、半径5米，正常结束只触发一次原终点爆发；取消、死亡、换房不追加爆发。
- 正常生成的普通怪、精英怪真实改用诱饵目标，结束恢复；正常生成的Boss始终免疫，原导演行为保持。
- 范围外、死亡、已退休、其他房间实例的目标不被错误影响；未知类别不能静默映射为普通怪或Boss。
- P1一级四组合及未学P1对照；原技能两敌反例、仅返航新增敌人反例；完整记录释放、登舟、返航结束时的技能时间、冷却及退款前后读数。
- 每次施法消耗、冷却起算、释放和终结事件唯一，实际退款恰为当刻剩余冷却乘对应等级比例。
- 舟与河流视觉保持基础表现，状态与返航朝向正确，不改变原寿命时钟。
- 正式能力准入、正常获取、选择、持有和释放流程分别验证；机制测试中的强制持有不等于玩家正常获取已通过。
