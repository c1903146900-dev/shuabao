# 刷宝 · Shuabao

3D 俯视高速 PVE ACT。目标为 1–5 人独立镜头、中文键鼠、Windows 客户端和 Linux 无头专服。

当前为两种房间交替的单人可玩原型：真实击杀奖励与18点成长、四项属性装备（AD/攻速/生命上限/CDR）、胜利阶段用药及纯数值海克斯。其余属性构筑、机制海克斯、锻体、联机与存档尚未开放。数值及药品策略均为明确标注的原型初值，不是可发布游戏。详见[操作、边界与验收](docs/INTEGRATION_CHECKPOINT_3.md)。

## 打开与检查

使用 Godot **4.6.3 stable** 标准版打开仓库根目录的 `project.godot`，按 F6/F5 运行。Blender **4.3.2** 用于已验证的 MCP 骨骼资产制作。引擎及工具不随仓库分发。

```sh
godot --editor --path .
# 在没有图形桌面的环境执行引擎检查：
bash scripts/check.sh
```

检查脚本仅验证编辑器导入与无头场景启动，不代表画面、MCP、动画往返或导出验证通过。整合链路已完成1280×720真实 MCP 运行与输入路由检查；独立QA已验证旧15e694版窗口输入；本次两房版本的独立窗口复验及压力回归待完成。HUD 使用仓库内 Noto CJK 字体，许可随资产提供。
