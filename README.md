# 刷宝 · 风厉 Windows 试玩

单人两房间战斗原型，非完整游戏。Windows x86_64 包约 52 MB。

[下载试玩 ZIP](https://raw.githubusercontent.com/c1903146900-dev/shuabao/refs/heads/playtest/windows-50f6bf3c8df2/shuabao-windows-playtest-50f6bf3c8df2.zip)

完整解压，保持 `shuabao-smoke.exe` 和 `shuabao-smoke.pck` 同目录，双击 EXE。按 K 学 Q，关面板后 Enter 开战。

- WASD 移动，鼠标瞄准，按住左键普攻。
- Q/E/R 使用已学技能，Shift 冲刺。
- K 技能，P 行装与补给，Esc 关面板。
- 准备或胜利后 Enter 进入下一房。
- 倒地后关闭结算，再按空格自救一次；真死亡后 F5 原房续战。
