# 刷宝 · Shuabao

3D 俯视高速 PVE ACT。目标为 1–5 人独立镜头、中文键鼠、Windows 客户端和 Linux 无头专服。

当前只有最小 Godot 项目骨架：地面、占位角色、俯视镜头、光源和中文启动 UI；尚无战斗、联机或存档，不是可发布游戏。

## 打开与检查

使用 Godot **4.6.3 stable** 标准版打开仓库根目录的 `project.godot`，按 F6/F5 运行。Blender **4.3.2** 为候选资产制作版本。引擎及工具不随仓库分发。

```sh
godot --editor --path .
# 在没有图形桌面的环境执行引擎检查：
bash scripts/check.sh
```

检查脚本仅验证编辑器导入与无头场景启动，不代表画面、MCP、动画往返或导出验证通过。图形运行需另验中文字体、退出按钮、1280×720 / 1920×1080 / 超宽窗口布局。当前中文字体依赖系统回退，打包前需选定可分发字体。
