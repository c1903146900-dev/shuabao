## Animation implementation direction
Use an authored 2D rig with continuous sleeve/robe deformation and rigid hand/brush assembly. Lower gait remains independent of upper source-phase gestures; add shared torso weight/breathing and restrained cloth follow-through driven by actual source/actor progress. Bake authored rig poses to atlas frames if that is simpler for world-depth display. Avoid independently generated hundreds of whole-body frames and avoid interpreting a two-quad renderer as proof of good animation.

Resource activation should be direction/action-specific after review: complete idle/run and basic/Q1 core first, then Q2/Q3, E and R. A missing unrelated R clip must not indefinitely block available run animation. Every enabled action needs real authored motion; explicit original-character fallback remains a temporary development path, not a fake static animation or final acceptance.

No game source, gameplay time, movement, damage, permissions or world effects are modified by this plan. No engine has run. Each new source/artifact is published and remotely byte-verified promptly through the designated backup publisher; reference-video redistribution is not part of the artwork backup request.
