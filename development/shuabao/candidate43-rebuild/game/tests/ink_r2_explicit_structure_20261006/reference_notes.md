# R2 自动密集敌群墨峰：官方参考与单一最小建议

记录时间：2026-10-06 UTC。研究范围仅为公开官方网页和本项目已有文档。本文件是建议，不是新的用户决定、运行实现、实机验收或平衡结论。

## 先给结论

保留原表的固定圆域；每一道出现前重新找圆域内更密集的敌群，在选定的固定地面点做短预警，再由地下顶出一簇墨峰。选点与技能序号、人物面向或任何60°旋转无关。基础四阶严格为7、9、13、20道。单峰建议使用半径2m的紧凑圆形足迹，不能默默沿用旧18×4m笔锋。

## 可借鉴的三个可读性原则

以下是根据官方机制文字推导出的本作设计建议，不是对未观看画面的描述。

- 把“整段持续区域”与“本次局部命中”分成两层。固定圆域边缘维持很淡的墨圈，当前峰底给更清晰的小墨印；玩家能分辨大招还在持续，以及下一道具体出现在哪里。依据是两项参考均在持续期内重复打击。
- 把选点和伤害留出短暂可读间隔。峰底先凝墨，随后顶起；锁点后不得追着敌人滑动。腾讯官方描述有投弹后延迟命中的过程，但这里0.18秒预警为本作新建议，不是照抄其时间。
- 每一道有一个清晰的顶起节拍，结束立刻退为淡墨。区域背景安静，伤害峰短促，持续大招也能读出连续打击次数；视觉簇里即使有三个尖峰，也只对应一次命中事件。

## 一个具体最小方案

### 固定域与圆形峰底

沿用未冲突原值：12m施法距离；四阶半径10/10.54/11.5/13m；持续5/5.5/6.5/8秒；基础冷却145/136/121/101秒；原收卷伤害及H16定义保留。领域中心在施法确认时固定，后续玩家、敌人移动都不带动领域。

每道为一个半径2m圆形峰底，内含一座不对称主峰和两条低矮侧脊；这一整簇叫“一道”，不是三道。主峰沿竖直方向顶起，墨脊可有固定的造型偏斜，但这种偏斜不参与选点或判定。无可碰撞山体，不增加阻挡、击退、击飞或减速。

### 每道重新密集评分，预警后固定位置

在每道预警开始时，读取当时在本固定域内、按既有资格规则有效且存活的敌人。候选点仅由这些敌人的中心与两两中心中点组成，并过滤为当前领域/房间内合法的落点。对每个候选点，统计实际与半径2m峰底相交的有效敌方身体数量，同一敌人只计一次。选择得分最高的候选点；同分以稳定坐标顺序、再以稳定敌人ID打破平局。这里是有限候选集内选最密处，并不声称求得连续空间的数学全局最优。

不增加Boss权重、血量权重或角度偏好。每道重新计算，故后面的峰会追随新的人群分布；本次预警点及足迹一旦确定就不再移动。命中时按该固定足迹查询当时的有效敌人，每道对每个目标最多提交一次伤害；先前被瞄准的敌人走开可以落空，其他有效敌人走入也可以被命中。

空域沿用当前决定文档的制作候选：消耗本次名额，在合法域内点显示无伤害墨峰，不把名额攒到后来。若施法/房间生命周期被既有取消规则取消，停止剩余事件；“严格N道”指未被取消的正常完整施放，不覆盖既有取消规则。

### 严格排完N道，同时保留0.3秒峰体

本建议把每道拆为：

- 相对该道开始0.00–0.18秒：地面墨印凝聚，固定落点预警
- 0.18–0.24秒：峰体从地下顶起
- 0.24秒：唯一伤害时点，伴随一次短墨花
- 0.24–0.32秒：峰形短暂保持
- 0.32–0.48秒：自上而下褪墨消散

峰体本身从0.18到0.48秒，恰好存在0.3秒，另有0.18秒地面预警。

设领域原持续为D、该阶用户指定总道数为N，道序i为0到N−1。每道开始时刻：

s_i = i × (D − 0.48) / (N − 1)

这是文档中的排程定义，不是运行代码。第一道在领域建立时开始预警，末道在D−0.24秒命中、D时消散，然后收卷结算。四阶预警起点间隔依次为0.753333…/0.6275/0.501666…/0.395789…秒；保存完整公式值，不以显示小数反复累加。各道有明确序号，一次完整施放只拥有N个名额，不靠“不断加间隔直到超时”推导数目。

当前决定文档中的kD/N是尚未实施的制作候选；若把它当预警开始，再加0.18+0.3秒，四阶末道会延至8.08秒。本方案是为消除这一具体边角提出的一个替代排程，不擅自更改决定文档。0.18、0.06、0.08、0.16秒及公式均是制作建议，非用户指定值，也非官方参考技能数值。

### 伤害起点及范围

建议另存一版明确的新四阶调参起点，不沿用旧长条笔锋伤害：单道40/55/80/120点 + 25/30/40/50%AP。仅计峰体、假设同一目标吃满全部道数，四阶总量为280/495/1040/2400点 + 175/270/520/1000%AP；这只是算术上限，未包括保持原定义的收卷伤害，也不代表预警可躲避、密集选点和实战目标移动情况下的平衡结果。

这张表是一个可调起点。用户已允许降低单道伤害，最终采用需由制作负责人显式版本化。不要把“峰更小”或“理论总量”当成已经平衡的证据。

### 临时美术与后续正式资产

临时表现只需一张地面淡墨圈、一张每道圆形预警墨印，以及同一套一主峰两侧脊的简化不对称峰簇；使用自地面以下升起、短停、溶解的固定三阶段。它用于验证“从地下顶起来”“落点先可读”“命中只有一次”，只能称临时美术，不能称正式完成。

正式资产后续应替换为专门制作的山水皴擦峰簇、地面渗墨和墨缘消散，保留完全相同的足迹、0.18秒预警、0.3秒峰体与伤害时点。不能由美术模型外形、骨骼、粒子数量或动画碰撞反向决定伤害。本文未制作或验证任何资产。

### H15暂锁，保留原两条意图

原表“万壑争流”同时包含山峰间隔缩短25%、山峰最终伤害提高30%。新基础总数7/9/13/20并未回答缩间隔以后增加多少道、如何处理末道预警与收卷边界，因此本小步仍把H15明确保持为未接入/不可获得，不假装已经支持。

保留原H15名称、两条数值、来源与待实现状态；在新基础排程和新伤害表版本化后，再单独定义它的完整有效排程与总数。不能把25%偷偷删掉，不能只实现30%后宣称H15完成，也不能把基础N上限误用为永久否决H15增密的规则。H16原收卷含义不受本建议改写。
