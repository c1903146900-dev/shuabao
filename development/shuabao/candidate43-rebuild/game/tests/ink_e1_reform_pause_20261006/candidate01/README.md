It calls the inherited `_e1_damage_batch` once per saved target. No paused next target is pre-claimed; a committed packet is never replayed. The last packet can pause too: cast finish and the E1/P1 terminal wait for resume.

P1's whole-reform enter/leave barrier and P2's source-frame barrier are retained around each actual drain. P2 is additionally blocked while any original reform remains pending, including the parent P2 fixed-step entry drain. The real source frame does not remain artificially on a call stack during pause. If the original callback retires the scope, no old step runs; a same-room cast cancellation can proceed into the one normal new tick. A repeated pause preserves the admitted tick in the existing accumulator.

Cancellation, death, owner/room retirement and the existing rest transient clear dispose the exact remaining queue and marks. Pending reform and active dispatch block premature victory. Packet identity checks, nominal amounts, original impact metadata, target order and cooldown initiation remain inherited.
