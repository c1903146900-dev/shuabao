# Base E2 on the current ordinary chain

This successor retains the current P1 lifesteal Sim, R1 navigation director,
single rest Session/Bridge, reward table, route ownership and original resources.
It adds base E2 to the real ordinary skill selector. H09/H10 stay closed.
Production changes only the adapter's first extends line; all prior runtime
sources and manifests remain frozen. Production preimages are stored here.

## Composition and identity

The three E2 donor layers are copied as e2_base.gd, e2_remainder.gd and
e2_boundary.gd. Each changes only its extends line: the former isolated E1
parent is replaced by the actual current P1/R1/lifesteal chain. Their historical
comments about undecided boundaries and no ordinary admission describe their
original donor scope. This new leaf's binding, catalog and verified boundary
decision supersede those comments for this composition.

sim.gd uses the same P1 collector and atomic final settlement. A real E2 launch
binds its original boat instance to the new root. Only packets owned by that
boat, cast, room and generation may contribute. Only a real complete-boat
terminal frame can end its damage stage. Parking, boarding input, cancelled
boats, forged terminal events and partial packets cannot prematurely pay P1.
The existing committed-supplement lifesteal callback reads the same committed
receipt, health authority, factor and cap; only its eligible E2 source is added.
No damage or hit is replayed. R1/BASIC remain outside P1.

The new Binding independently admits exact Sim/Session/Bridge/navigation paths.
Its map is the complete frozen Rest/P1/R1 closure plus the independent E2 closure
and this leaf. The source audit reconstructs every ancestor map and explicit
replacement link before comparing the flattened map. The prior production SHA
may advance only to this leaf's exact adapter SHA. The old binders remain strict
and reject the successor; no old script identity or hash rejection is bypassed.

BoatCommon replaces its parent RainCommon only at construction and adds the E2
burst impact snapshot; its E1/common behavior and the same health owner remain.
No old isolated navigation installer or director is imported into the live Sim.

## Player behavior

The exact 1.1 m source front stops at its first physical room-boundary contact.
It never uses the hero's inset for movement and never slides along the edge.
The original voyage clock, expiry burst, per-target ledger and cooldown persist.
Solid walls do not block the boat. Boarding uses the exact current boat point:
if the hero cannot stand there, boarding is rejected and the boat remains.
The ordinary selector, card and temporary source-front view explain this.
The marker is temporary functionality, with no new final boat art or audio.

Q/R preview and mouse-pair ownership remain inherited. The E2 router consumes a
physical down/up pair and requires a real release after a pause/menu. E1's real
release path, including a release received while its room is hidden, survives.

Use the existing external guard, suggested 30 seconds and 768 MiB per process.
Require exit 0, reaped PID, all five required groups, exact binding/gate SHA,
and no SCRIPT ERROR, parse/runtime errors, leaked ObjectDB/resources, OOM or
guard termination. Green JSON cannot override errors in raw logs.

The five groups cover new exact admission and the real one-SP E2 selector;
whole-boat single/multiple-target P1 and existing supplement lifesteal; paused
boat remainder/queued E and separately real Q2 hostile control; retained E1
release/Q2 order and current R1; menu old/new E ownership and real rest entry.
The hostile-control checks use the real enemy director on explicitly prepared
warning-state actors. They do not inject _q2_enemy_hits packets. The existing
old-E2-local → queued E → old-Q2 phase convention remains explicit; this suite
does not claim all older events globally precede newer input or prove arbitrary
callback-created nested events. The earlier 46-check injected differential is
historical context, not this combination's native-control evidence.

The prior 85/103 and other full matrices are not rerun. Mechanism direct ranks,
positions and AI warning states are test fixtures; the two route combats use
explicit source damage. Neither proves natural play, native input, final art,
audio or an entire first-floor Boss loop. At authoring, engine/finite/native
verification is NOT_RUN. Runtime receipts belong outside this frozen source.
