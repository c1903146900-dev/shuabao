# Unified shared25 db0f9 source-tools backup

This source-only archive contains the exact reviewed db0f9 guard, its required validators/link/adapter and pinned adapter-review input, nine original primitives, paced-RSS factory, Owner script/matrix, contracts and six selected original pure-test modules. It includes the minimal old f833 guard plus identical adapter only for shared25 differential testing. It does not replace the existing production source or G26 PM03/PM04 backups.

The 34 files contain 30 unchanged originals and four new backup-only documentation/manifest/verifier files. The six packaged pure-test modules were checked from a restored layout (162 methods); this is not all 272 historical methods and establishes no engine or business admission. No actual jobs, Store/handoff data, actual process identities, private workspace paths, credentials, runtime logs/receipts or game project are included. Synthetic fixture IDs/paths in original tests are retained.

## Safe restore

Use ARCHIVE_MANIFEST.json as the exact allowlist. Read each 32KiB part as binary, using GitHub fetch_file encoding base64 when using that connector. Verify every part length/SHA256 and contiguous sequence/offset, then verify the joined archive SHA256 before decompression. Require exactly the 34 listed regular members under unified_tools_db0f9_source/. Reject absolute paths, traversal, duplicate/unlisted members, links, special files and PAX/GNU extensions. Verify all member lengths/hashes before writing to a new empty directory.

The extracted BUNDLE_MANIFEST.json must exactly match the companion original manifest. From the extracted unified_tools_db0f9_source directory run python -B verify_sources.py. Read its README for the preserved relative lookup layout and selected pure tests. No engine runs as part of the verifier.

## Portability and authority

The guard already accepts --workspace; moving unchanged bytes does not change their source SHA. Its original official engine path and engine hash are retained. Actually editing that path or any source creates a new identity and requires independent review plus fresh exact job pins. No adaptation or new engine authorization is provided here. This archive cannot resume an old job; production source, generated import proofs, fresh job/output/ownership evidence and explicit execution permission remain separate.
